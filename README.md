# Contador

Contador simple para iOS. Múltiples contadores organizados por categorías, con historial y vista de calendario.

## Qué hace

- Contadores independientes, cada uno con su nombre
- Organización en categorías y subcategorías
- Sumar y restar con un toque
- Historial de cada cambio
- Vista de calendario para ver la actividad día por día
- Exportar e importar tus datos como archivo

Sin cuentas, sin registro y sin anuncios.

## Privacidad

La app no recolecta ni transmite ningún dato. Todo se guarda localmente en tu dispositivo.

Ver [política de privacidad](PRIVACY.md).
